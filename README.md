## 📌 Featured Projects

### 1. Wire Bonding Process Optimization

반도체 패키징 교육 과정에서 수행한 **Wire Bonding 공정 실습 프로젝트**입니다.

Auto Wire Bonder를 활용하여 공정 조건을 변화시키고 Wire Pull Test를 통해 접합 강도 및 파단 형태를 분석하는 것을 목표로 했습니다.

**주요 내용**

* DOE 기반 실험 조건 설계
* Auto Wire Bonder 공정 수행
* Ultrasonic Power / Bond Force / Bonding Time 변수 분석
* Wire Pull Test 수행
* Wire Pull Strength 분석
* Failure Mode 분석
* 최적 공정 조건 도출

> **Process Parameter → Experimental Design → Measurement → Data Analysis → Optimization**

이 프로젝트를 통해 단순히 장비를 사용하는 것에 그치지 않고, **공정 변수와 품질 특성 사이의 관계를 정량적으로 분석하는 공정 엔지니어의 접근법**을 경험했습니다.

## 📈 What I Focus On

제가 가장 중요하게 생각하는 역량은 **공정 최적화 능력**입니다.

공정 엔지니어는 단순히 주어진 공정을 운영하는 사람이 아니라,

1. 공정 문제를 정의하고
2. 영향을 미치는 변수를 파악한 뒤
3. 적절한 실험을 설계하고
4. 데이터를 통해 결과를 분석하며
5. 최적의 공정 조건을 찾아
6. 안정적인 생산 조건으로 만드는

역할을 수행한다고 생각합니다.

따라서 앞으로도 **DOE · Statistical Analysis · Data Visualization · Failure Analysis** 역량을 지속적으로 강화할 계획입니다.
